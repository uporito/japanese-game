# japanese-game

A small rogue-like game to gamify personal Japanese learning.

## Current state (V1)

- **Runs:** 3 acts (N5, N4, N3), 3 fights per act, 10 words per fight
- **Two encounter types**, rolled per fight: pick the English **meaning** (訳) or the hiragana **reading** (読) of a word
- **Lives** carry over across the run: 3 max, +1 after each cleared fight, full heal at each new act. Run over at 0
- **Map** of the run: hover, focus or click "Map" during a fight; shown in full between fights
- **Word library** from the main menu: all 2,963 N5-N3 words with per-word seen / correct / wrong stats (overall or per encounter type), filters (level, word class, kana-only, status, search), sorting, and a stats reset
- Stats are saved in the browser's localStorage after every answer
- Answer by clicking or with keys 1-4

## Getting started

Requires Node 20+.

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # unit tests (Vitest)
npm run build    # typecheck + production build
```

**Debug:** a "Next Act" button (skip to the next act as if the current one were cleared perfectly) shows in dev builds, or in any build with `?debug=1` in the URL.

## Vocabulary data

`src/data/vocab/*.json` is generated by `scripts/build-vocab.ts` from [OpenJLPT](https://github.com/evanclan/OpenJLPT). To regenerate, download `data/json/vocab/{n5,n4,n3}.json` from OpenJLPT into `scripts/source/` and run `npm run build:vocab`.

The data is CC BY-SA 4.0, built on JMdict (EDRDG) and Jonathan Waller's JLPT lists. See [src/data/LICENSE-DATA.md](src/data/LICENSE-DATA.md). JLPT levels are community estimates; no official lists exist.

## Project structure

```
scripts/build-vocab.ts   OpenJLPT -> slim per-level JSON
src/
  data/                  generated vocab, loader, word class mapping
  game/                  UI-agnostic logic (all unit-tested)
    runEngine.ts         run reducer: acts, fights, healing, debug skip
    runConfig.ts         tuning constants (lives, heal, sizes, encounter weights)
    fightEngine.ts       fight reducer and word selection
    questions/           meaning and reading question builders + distractors
    stats.ts             localStorage stats store
    library.ts           library filtering and sorting
  screens/               Menu, Run (Fight / Interlude / RunResult), Library
  components/            cards, answers, lives, HP bar, run map, debug controls
```

Tech: Vite + React + TypeScript, plain CSS, Vitest, no backend.
